# Atlas H5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a mobile-first Atlas scene report H5 that saves validated reports into the current operations system.

**Architecture:** Add explicit Atlas category/report helpers and API routes beside the existing generic module architecture. Serve a standalone mobile page at `/h5/atlas-report` so the desktop admin UI remains stable.

**Tech Stack:** Node.js, Express, better-sqlite3, static HTML/CSS/vanilla JS, existing Node assert tests.

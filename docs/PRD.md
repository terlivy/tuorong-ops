# 运营业务管理系统 PRD

## 1. 产品目标

建设一个面向运营团队的业务管理系统，统一管理合作门店/合作商资产、人员、项目产品、业务机会、执行任务、结算、供需撮合、供应链订单和问题闭环。

系统需要支持当前数据采集业务，并能扩展到售电业务、供需撮合、供应链业务。

## 2. 用户角色

- 管理员：维护账号、基础数据、业务配置、查看全部数据。
- 业务负责人：维护资产、业务机会、跟进和成交情况。
- 执行负责人：维护采集、售电办理、供应链订单等执行任务。
- 财务/结算人员：维护应收、应付、利润、结款状态。

## 3. 核心模块

### 资产中心

管理可复用业务资产，包括合作门店、合作商、公司、联系人、电话、微信、地址、地图坐标、可做业务标签、合作状态、结算状态。

### 人员中心

管理业务人员、采集人员、负责人等人员资料。

### 项目/产品中心

管理数据采集、售电、供应链、供需撮合等业务类型的项目配置、上游甲方、价格规则和状态。

### 业务机会管理

管理线索、跟进、洽谈、成交和流失，记录预计金额、成交金额和下次跟进时间。

### 执行任务管理

管理业务成交后的执行动作，包括采集任务、售电办理任务、供应链执行和供需撮合执行。

### 结算管理

管理上游应收、下游应付、合作商应付、成本、收入、毛利润、发票和结算状态。

### 供需管理

管理门店需求、供应资源、品类、数量、预算和撮合状态。

### 供应链管理

管理供应商、商品/服务、门店订单、数量、单价、总金额、配送状态和回款状态。

### 问题管理

管理所有模块产生的问题、负责人、优先级、截止日期和处理结果。

## 4. 非功能需求

- 支持账号密码登录。
- 支持 CSV 导入导出。
- 支持 Docker 部署。
- 数据持久化到 SQLite。
- 支持后续迁移到 MySQL/PostgreSQL。

# 运营业务管理系统 SOP

## 1. 首次部署

1. 复制 `.env.example` 为 `.env`。
2. 修改 `JWT_SECRET`、`ADMIN_USER`、`ADMIN_PASSWORD`。
3. 如需资产中心显示高德地图，填写 `AMAP_KEY` 和 `AMAP_SECURITY_CODE`。
4. 执行 `docker compose up -d --build`。
5. 浏览器访问服务器 `http://服务器IP:3000`。
6. 使用 `.env` 中的管理员账号登录。

## 2. 日常录入流程

1. 在资产中心录入合作门店或合作商。
2. 在人员中心录入业务人员、采集人员、负责人。
3. 在项目/产品中心配置数据采集、售电、供应链或供需项目。
4. 在业务机会管理中新建业务机会并持续更新阶段。
5. 成交后在执行任务管理中新建任务。
6. 执行完成后进入结算管理，录入应收、应付和利润。
7. 若过程出现异常，在问题管理中新建问题并跟踪关闭。

## 3. CSV 导入导出

1. 进入对应模块。
2. 点击“导出 CSV”下载模板。
3. 按导出的表头填写数据。
4. 点击“导入 CSV”上传文件。

## 4. 数据备份

Docker 部署时数据库位于：

```text
./data/ops-platform.db
```

建议每天备份 `data` 目录。

## 5. 升级发布

1. 停止容器：`docker compose down`。
2. 备份 `data` 目录。
3. 拉取或上传新代码。
4. 执行：`docker compose up -d --build`。
5. 登录系统检查核心模块数据。
